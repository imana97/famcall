# Contributing

Open an issue for substantial changes, fork this repository, and submit a focused pull request with validation evidence. Do not include real phone numbers, call audio, contacts, credentials, private keys, or production logs. Use fictional test numbers and generated audio.

All app text belongs in the localization catalog. English is initially supported; layout direction is always left-to-right.

Only silvergrid may approve or merge changes and approve releases. Contributors must not bypass branch protections or trigger privileged code from fork pull requests. Release and deployment credentials belong only in protected environments.

Network tests must report measured conditions, call success, recovery, and audio continuity. A passing UI flow alone does not prove voice-call reliability.
