CONSTRAINT
Use hosted devices; do not install, launch or test on the owner's personal phones.
The local personal-phone setup has been discontinued. A cloud UI pass alone does
not satisfy the two-way speech, network recovery, push or signing release gates.

eligibility, remaining minutes and feature entitlements must be checked before use.
The owner requested evaluation of BrowserStack's free trial. Its account page now
initially showed 100 unused App Automate minutes. The API reports Free plan and

build duration alone is not a billing statement. Recheck before further runs.

Firebase Test Lab: the existing Blaze pricing tier includes 30 physical-device
minutes and 60 virtual-device minutes per day. Additional physical time is $5 per
device-hour; virtual time is $1 per device-hour. Android Device Streaming has a
separate allowance of 30 minutes per month, then $0.15/minute; do not confuse that
interactive product with the daily Test Lab allowance. Test Lab is a practical
candidate for repeatable install/UI checks. Its documented native test frameworks
require adaptation from Maestro; no two-way voice fixture is established here.

AWS Device Farm: the public offer currently advertises a one-time 1,000 device-
minute trial (a limited-time increase from 250), then $0.17/device-minute. A ten-
minute two-device session uses at least 20 device-minutes, or $3.40 after the trial,
before billed preparation/cleanup. AWS documents real Android/iOS devices and
network shaping for bandwidth, delay, jitter and loss in both directions, with
changes during a run. This makes it a candidate for weak-network testing, subject
to verifying actual media impairment, microphone injection/output capture, paired
device concurrency and iOS signing limitations. Wi-Fi shaping is not carrier
coverage. Do not purchase unmetered/private-device subscriptions for this pilot.
AWS's standard iOS re-signing removes push-notification entitlements, so that
route cannot validate production incoming-call push. Media-file upload support
does not establish microphone injection or in-call audio recording support.

TestingBot's open-source program advertises free unlimited automated testing,
real Android/iOS devices and two concurrent tests for qualifying active public,
non-commercial projects with an OSI-approved license. FamCall's public MIT license
alone does not establish non-commercial eligibility or approval. Its requested
attribution and actual voice/network features also need review before adoption.
No application has been submitted and no vendor has been contacted.

BrowserStack's public trial includes 100 App Automate minutes and a separate 30
App Live minutes. This account reports five concurrent slots; its Pro audio and
network features remain unqualified. Evaluate entitlement before enabling paid
features; no paid upgrade is authorized by a trial evaluation.

Use existing local emulators for the bulk of repeatable checks, Test Lab for
limited recurring device coverage, and a qualified trial for the remaining cloud
checks. No researched free offer yet proves complete two-way speech, background
push and production-signing coverage on both platforms. Keep those gates open.

BROWSERSTACK CAPABILITIES
App Automate supports the existing Maestro approach on real Android and iOS
devices. Start by checking account access, enabled features, available concurrent
sessions and trial minutes. Do not purchase a subscription without owner approval.
Two actual app endpoints need overlapping device sessions and a shared backend.

Its Maestro audio injection supports selected Android devices, not iOS, and is
listed for Device Cloud Pro or higher plans. Session video can include device
output audio on Android 11+ and iOS 15+. Qualify that capture with a known signal:
normal media playback support does not by itself prove in-call audio capture.
Android-to-iPhone received speech can be evaluated only after this qualification;
the reverse iPhone microphone path remains an explicit gap.

Maestro network settings apply for the whole build. Mid-call network changes need
Appium's update_network API or a separately verified impairment gateway. Network
profiles require a paid plan. The documentation does not establish that FamCall's
selected UDP media path is impaired: measure actual relay traffic, packet loss,
jitter and RTT before counting any weak-network or outage result.

Uploaded iOS builds may be re-signed by the provider. Preserve a separate plan for
original signing, App Attest, APNs/VoIP push and actual TestFlight distribution.
Do not treat a re-signed demo app as production authenticity or delivery evidence.

ALTERNATIVES
Kobiton documents automated audio injection for iOS/XCUITest and Android/
UiAutomator2 through Bluetooth audio. It is a candidate for the missing iPhone
voice path, subject to hosted/private-device availability, plan cost, audio-route
qualification and network shaping. Do not assume its public device pool includes
that hardware feature. A Bluetooth route does not prove built-in microphone,
earpiece, proximity-sensor or acoustic echo behavior.

Sauce Labs' documented audio injection replaces speech-recognition input and
excludes React Native. It is not evidence of continuous WebRTC microphone support.
Firebase Test Lab is an option for supplementary installation and UI compatibility
coverage; no continuous bidirectional microphone/voice harness is established here.
